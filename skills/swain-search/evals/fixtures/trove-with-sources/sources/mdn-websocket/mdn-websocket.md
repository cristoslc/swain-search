# WebSocket API

The WebSocket API enables bidirectional communication between a user's browser and a server.

## Constructor

WebSocket(url, protocols) — creates a new WebSocket connection.

## Events

- open — connection established
- message — data received
- close — connection closed
- error — error occurred

## Methods

- send(data) — send data to server
- close() — close connection
